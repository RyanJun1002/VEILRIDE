# Third-party assets

The runtime includes only assets whose licenses permit redistribution through
this public GitHub repository and GitHub Pages deployment.

## Included

- Poly Haven assets listed in `public/textures/environment/sources.txt` (CC0)
- Poly Haven Dense Sand (CC0)

## Requested but not included

- SketchUp Texture Club `Highway road PBR texture seamless 21877`
- Poliigon textures `12876`, `12238`, and `10787`

These sources prohibit redistribution or making the texture files directly
downloadable. A public web game exposes its texture requests and the repository
also distributes the files, so they cannot be committed here without separate
permission covering this use. The existing procedural road remains in place,
and city walls use the requested CC0 Poly Haven red-brick and stone-wall assets.
